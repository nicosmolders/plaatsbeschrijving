# inplaatsbeschrijvingen.be

Website van Inplaatsbeschrijvingen. Statische site: wat hier staat, staat online.

## Online zetten (Cloudflare Pages)
Het Cloudflare Pages-project is gekoppeld aan deze repo (branch `main`).
Elke wijziging op `main` gaat binnen een minuut automatisch online.

- Build-commando: leeg
- Uitvoermap (build output directory): `/`

## Bestanden
- `index.html` en de mappen: de pagina's
- `_astro/`: stijlbladen
- `_redirects`: oude Wix-adressen naar de nieuwe pagina's
- `_headers`: beveiligings- en cache-instellingen
- `404.html`: pagina voor onbestaande adressen
